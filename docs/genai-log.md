## 2026-10-29 — observability, health, API contract, README

### Written by AI, reviewed by me
- `internal/reqid` (new package): middleware that reuses a well-formed incoming `X-Request-ID` or creates a 128-bit random id, stores it in the context and echoes it in the response; a `slog.Handler` wrapper that adds `request_id` to every line logged with that context. Incoming ids are validated (letters, digits, `.`, `_`, `-`, up to 64 characters) so a caller cannot inject fake log lines. The wrapper also overrides `WithAttrs`/`WithGroup`, otherwise `slog.With(...)` would silently drop the id; a test covers that. Review: I read the package and its tests, and checked the id in real logs.
- `internal/api/middleware.go` (access log line per request, with the real status code), `internal/api/health.go` (`/healthz` liveness checks nothing; `/readyz` pings Postgres with a 1s limit and returns 503 when it is down, external systems excluded), and a `documents served` summary line in my handler. Review: I checked them against section 7 of the design doc.
- `internal/aggregator/calllog.go`: `SlogCallLogger`, a decorator that writes one `source call` log line, then passes the call to the Postgres store. It keeps logging out of my aggregator code; `main.go` chooses the chain. The three `slog.Warn` calls in my aggregator became `slog.WarnContext(ctx, ...)` so they carry the request id. Review: I traced the wiring in `main.go`.
- `internal/source/sales.go`, `internal/source/service.go`: three lines each to forward the request id in `X-Request-ID`. Both mock servers now log it. Review: I compared the two clients and grepped one id across the three containers.
- `cmd/server/main.go`: the middleware chain, the health routes, and graceful shutdown on SIGINT/SIGTERM (in-flight requests get up to 10s). `compose.yml`: a healthcheck on `/readyz`. Review: I ran `docker compose stop server` and saw the `shutting down` log line.
- Tests: `internal/reqid/reqid_test.go`, `internal/api/api_test.go` (health, handler with valid, lower-case and invalid VINs, access log line), `internal/source/reqid_test.go` (header forwarded by both clients, no header without an id). Review: `go test -race ./...` green.
